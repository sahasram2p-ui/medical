# Medical Chatbot

Medical and health information-only Flask + Gemini chatbot.

This provides general educational information only. It is not a substitute
for a qualified healthcare professional, diagnosis, or prescription.
For emergencies, seek immediate medical care.

Setup:
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. Put your Gemini API key in .env
5. python app.py
6. Open http://127.0.0.1:5000
